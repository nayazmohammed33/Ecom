# E-Commerce App

A simple and responsive e-commerce application built with React. The application allows users to browse products, add items to the cart, update quantities, and remove products using Context API for global state management.

## Features

- Product Listing
- Product Details Page
- Add to Cart
- Remove from Cart
- Update Product Quantity
- Cart Total Calculation
- Context API State Management
- Responsive Design

## Tech Stack

- React.js
- Context API
- JavaScript (ES6+)
- CSS

## Learning Outcomes

- React Components & Props
- React Hooks
- Context API for State Management
- Shopping Cart Implementation
- Dynamic Rendering
- State Synchronization Across Components
